Gameplay Video Score Extraction Pipeline

Built an end-to-end ML pipeline to extract on-screen gameplay scores from long-form streaming videos and align scores to timestamps for validation and downstream analytics. Reduced video processing time by 60%+.

Performance

60%+ faster processing

Scale

Parallel cloud ingestion

Stack

Ray • Databricks • MLflow

Problem

The Applied AI team needed to extract gameplay scores from streaming videos for Quality of Experience (QoE) analysis. Long-form videos required efficient processing, and manual extraction was not scalable. The challenge was building a pipeline that could handle large video files, process them in parallel, and extract structured data reliably.

Approach

  • Parallel Cloud Ingestion: Implemented multithreaded downloads from AWS S3 with Ray-based task parallelism for distributed computing
  • Video Preprocessing: Automated clip splitting with FFmpeg, frame processing with OpenCV
  • Scalable Processing: Ran jobs in Databricks using PySpark for distributed data processing
  • Experiment Tracking: Used MLflow to track experiments, model versions, and artifacts
  • Score Extraction: Applied computer vision techniques (OCR) to extract on-screen scores
  • Timestamp Alignment: Aligned extracted scores to video timestamps for validation and analytics

Results

  • Performance: Reduced download and processing time by 60%+ for large videos through parallel processing
