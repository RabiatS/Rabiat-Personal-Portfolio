Spotify vs AI Research Study

A UX research and design project exploring how Spotify listeners perceive AI-generated music, and how clearer labeling and controls can build trust in the listening experience without diminishing enjoyment.

Focus

Trust • Transparency • UX

Methods

Research • Design • Testing

Deployed

Live Study ↗

Research Question

How might Spotify help listeners distinguish AI-generated music from human-created tracks without hurting the listening experience? As AI-generated music becomes more prevalent, platforms need transparent labeling strategies that build user trust while maintaining engagement.

Approach

  • User Research: Conducted interviews and surveys to understand listener perceptions of AI vs human music
  • Design Exploration: Explored different labeling approaches (badges, metadata, controls)
  • Prototype Development: Built interactive research study website using TypeScript and React
  • Data Collection: Designed study flow to collect user preferences and trust metrics
  • Analysis: Analyzed how different labeling strategies affect user perception and trust

Key Findings

  • Users value transparency but don't want AI labels to dominate the interface
  • Clear, unobtrusive labeling can build trust without reducing enjoyment
  • User controls (filtering, preferences) are important for user agency
  • Context matters: different labeling approaches work better in different parts of the app

Technical Implementation

Built a research study website deployed on Vercel. The site includes:

  • Interactive music comparison interface
  • Survey and data collection forms
  • Responsive design for multiple devices
  • Analytics integration for research data
